# Employees With the Same Salary

## ❓ Problem Statement
Find employees who earn the same salary.

Output the worker id along with the first name and the salary in descending order.

---

## 💻 SQL Solution

```sql


/*
WITH cte AS (
SELECT 
    worker_id,
    first_name,
    salary,
    LEAD(worker_id) OVER(ORDER BY salary DESC) AS nxt_id,
    LEAD(first_name) OVER(ORDER BY salary DESC) as nxt_name,
    LEAD(salary) OVER(ORDER BY salary DESC) as nxt_sal
FROM worker
)
SELECT
    worker_id,
    first_name,
    salary
FROM cte 
WHERE salary = nxt_sal
UNION ALL 
SELECT
    nxt_id as worker_id,
    nxt_name as first_name,
    nxt_sal as salary
FROM cte
WHERE salary = nxt_sal
ORDER BY salary DESC
*/

-- Another Soln. (BETTER)
WITH cte AS (
SELECT
    worker_id,
    first_name,
    salary,
    COUNT(worker_id) OVER(PARTITION BY salary) as cnt
FROM worker
)
SELECT 
    worker_id,
    first_name,
    salary
FROM cte 
WHERE cnt > 1
ORDER BY salary DESC
