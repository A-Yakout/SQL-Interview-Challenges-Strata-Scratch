# Find the percentage of shipable orders



**Difficulty:** 🟡 Medium

---

## ❓ Problem Statement
Find the percentage of shipable orders.
Consider an order is shipable if the customer's address is known.

---

## 💻 SQL Solution

```sql


SELECT
    SUM(CASE WHEN c.address IS NOT NULL THEN 1 ELSE 0 END)*100.0 / COUNT(o.*) AS percent_shipable
FROM orders o
JOIN customers c
ON o.cust_id = c.id
